SELF STUDY 04

함수 인자는 어떻게 매칭되는가 — default, packing, unpacking, *args, **kwargs

이 장의 목표는 *args와 **kwargs를 외우는 것이 아닙니다. 호출할 때 전달한 객체들이 어떤 매개변수 이름에 연결되는지, 그리고 왜 어떤 함수는 인자를 명시하고 어떤 함수는 여러 인자를 모아 받아야 하는지를 이해하는 것이 목표입니다.

먼저 판단 기준부터
  • 대부분의 함수는 def create_user(name, email, active=True)처럼 매개변수를 명시적으로 쓰는 편이 읽기 좋습니다.
  • *args/**kwargs는 인자 개수가 실제로 가변적이거나, 받은 인자를 다른 함수에 그대로 전달해야 할 때 특히 유용합니다.
  • 따라서 “고급 문법이니까 많이 쓰는 것”이 아니라 문제에 맞을 때 쓰는 도구입니다.

1. 가장 단순한 매칭 — positional과 keyword

def greet(name, message="안녕하세요"):
    print(name, message)

greet("Kim", "반갑습니다")
# 위치로 매칭
# name    → "Kim"
# message → "반갑습니다"

greet(message="반갑습니다", name="Kim")
# 이름으로 매칭

positional argument는 위치를 기준으로, keyword argument는 매개변수 이름을 기준으로 연결됩니다. 결국 매개변수도 함수 호출 동안 객체를 가리키는 이름입니다.

2. default argument — 호출자가 생략했을 때만 사용

greet("Kim")
# name    → "Kim"
# message → 함수가 가지고 있던 기본값 "안녕하세요"
mutable default의 핵심은 “정의 시점”입니다.
def f(items=[])의 []는 함수를 호출할 때마다 평가되는 것이 아니라, def 문이 실행되어 함수 객체를 만들 때 평가되어 기본값으로 보관됩니다.
def add(value, items=[]):
    items.append(value)
    return items

print(add(1))  # [1]
print(add(2))  # [1, 2]

print(add.__defaults__)
# 같은 기본값 list 객체가 함수에 보관되어 있음을 확인할 수 있다.
def safe_add(value, items=None):
    if items is None:
        items = []      # 이 줄은 함수를 호출할 때 실행된다.
    items.append(value)
    return items

print(safe_add(1))  # [1]
print(safe_add(2))  # [2]

3. packing — 여러 인자를 하나의 구조로 모으기

먼저 작은 예제로 모양을 확인합니다.

def show(first, *args):
    print("first:", first)
    print("args :", args)

show(10, 20, 30, 40)
# first → 10
# args  → (20, 30, 40)

*args는 남은 positional argument들을 tuple로 모읍니다. args라는 이름은 관례일 뿐이며 핵심은 앞의 *입니다.

def show(name, **kwargs):
    print("name  :", name)
    print("kwargs:", kwargs)

show("Kim", age=30, active=True)
# name   → "Kim"
# kwargs → {"age": 30, "active": True}

**kwargs는 남은 keyword argument들을 dict로 모읍니다.

4. unpacking — 하나의 구조를 여러 인자로 펼치기

def total(a, b, c):
    return a + b + c

values = [10, 20, 30]
print(total(*values))
# total(10, 20, 30)처럼 펼쳐 호출

options = {"a": 10, "b": 20, "c": 30}
print(total(**options))
# total(a=10, b=20, c=30)처럼 펼쳐 호출
같은 *가 반대 방향으로 보이는 이유
  • 함수 정의의 *args/**kwargs: 여러 인자를 모은다 — packing
  • 함수 호출의 *values/**options: 묶여 있는 값을 인자로 펼친다 — unpacking

5. 대입에서도 unpacking이 일어난다

point = (10, 20)
x, y = point

first, *middle, last = [1, 2, 3, 4, 5]
# first  = 1
# middle = [2, 3, 4]
# last   = 5

여기서도 본질은 같습니다. 하나의 iterable에서 값들을 꺼내 여러 이름에 연결합니다. 단, def f(*args)의 args는 tuple이고 대입의 *middle은 list가 된다는 차이는 기억해 두세요.

6. 복합 시그니처를 왼쪽부터 읽기

def process(a, b=20, *args, mode="normal", **kwargs):
    return a, b, args, mode, kwargs

print(process(10, 30, 40, 50, mode="fast", debug=True))
# a      = 10
# b      = 30
# args   = (40, 50)
# mode   = "fast"
# kwargs = {"debug": True}

8. 심화: 실제로 *args/**kwargs가 필요한 순간 — 함수 호출을 중계할 때

작은 예제로 문법을 알았다면 이제 “왜 이 문법이 존재하는가”를 봅니다. 로그 decorator는 나중에 어떤 함수에 붙을지 미리 알 수 없습니다. 함수마다 인자 구성이 다르기 때문입니다.

def create_user(name):
    return {"name": name}

def calculate_total(price, quantity, discount=0):
    return price * quantity - discount

def save_report(path, *, overwrite=False):
    return f"{path} 저장 (overwrite={overwrite})"

세 함수의 시그니처는 서로 다릅니다. decorator가 각각에 맞춰 wrapper(name), wrapper(price, quantity, discount), wrapper(path, overwrite=False)를 따로 만들면 재사용할 수 없습니다.

def log_call(func):
    def wrapper(*args, **kwargs):
        print(f"[CALL] {func.__name__}")
        print("args  :", args)
        print("kwargs:", kwargs)
        result = func(*args, **kwargs)
        print(f"[DONE] {func.__name__}")
        return result
    return wrapper

create_user = log_call(create_user)
calculate_total = log_call(calculate_total)
save_report = log_call(save_report)

print(create_user("Kim"))
print(calculate_total(15000, 3, discount=5000))
print(save_report("daily.txt", overwrite=True))
calculate_total(15000, 3, discount=5000)
                  │
                  ▼
wrapper가 받음
args   = (15000, 3)
kwargs = {"discount": 5000}
                  │
                  │ func(*args, **kwargs)
                  ▼
calculate_total(15000, 3, discount=5000)
                  │
                  ▼
                결과 반환

여기서는 *args/**kwargs가 단순히 “많이 받을 수 있는 편한 문법”이 아닙니다. 원래 함수의 호출 형태를 모르더라도 받은 인자를 그대로 중계하기 위한 장치입니다. SELF STUDY 08의 decorator에서 이 패턴을 다시 사용합니다.

객체 참조와 복사 심화 — shallow copy와 deepcopy

복사는 객체 그래프의 어떤 화살표를 공유하느냐의 문제

a → outer A ─┬→ inner X
             └→ inner Y
b → outer B ─┬→ inner X
             └→ inner Y

shallow copy는 outer만 새로 만들 수 있고, deepcopy는 중첩 참조를 따라 필요한 내부 객체까지 독립 복제를 시도합니다.

Week 3에서 배운 “변수는 객체를 가리키는 이름” 모델을 실제 버그와 연결합니다. 특히 리스트 안에 리스트, dict 안에 dict처럼 중첩된 mutable 객체가 있을 때 얕은 복사의 의미가 중요합니다.

핵심

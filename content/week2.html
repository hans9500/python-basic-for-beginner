형 변환 — int(), float(), str()

형 변환(type conversion)은 어떤 값을 다른 타입의 형태로 해석하거나 표현한 결과를 얻는 일입니다. 1주차의 객체 모델로 보면 원래 객체 자체를 직접 바꾸는 동작이 아니라, 변환된 타입의 결과를 얻는다고 이해하면 됩니다.

세 가지 변환 함수

  • int(x) — x를 정수 형태의 결과로 변환
  • float(x) — x를 실수 형태의 결과로 변환
  • str(x) — x를 문자열 형태의 결과로 변환

SECTION 03

try / except — 에러를 안전하게 처리하기

예외가 생기면 실행 흐름은 어디로 갈까?

try:
    print("A")
    age = int("abc")   # ValueError
    print("B")         # 실행되지 않음
except ValueError:
    print("C")
print("D")

예외가 발생하는 순간 try의 남은 정상 흐름은 중단되고 일치하는 except를 찾습니다. 따라서 A → C → D 순서입니다.

s2에서 int("스무살")은 ValueError를 낸다고 했죠. 사용자가 잘못된 값을 입력할 때마다 프로그램이 오류로 중단되면 쓰기 어렵습니다. try/except는 에러가 났을 때 프로그램이 멈추지 않고 미리 정해둔 방식으로 처리하게 해줍니다.

조금 뒤에 다시 연결합니다

while과 break를 배운 뒤에는 try/except를 합쳐 "올바른 값을 입력할 때까지 계속 묻기" 패턴을 다시 만들어봅니다. 여러 종류의 예외를 나누어 처리하는 방법은 리스트와 딕셔너리를 배운 뒤 예제로 확장하면 더 이해하기 쉽습니다.

이 섹션의 핵심
  • try: 블록에 시도할 코드, except 에러종류: 블록에 처리할 코드.
  • 예상한 에러를 처리하면 프로그램이 그 자리에서 비정상 종료되지 않고 다음 흐름으로 이어질 수 있다.
  • 지금은 숫자 변환에서 자주 만나는 ValueError부터 확실히 익힌다.
  • 모든 코드를 무조건 try로 감싸지 말고, 실패할 수 있고 처리 방법을 알고 있는 부분을 감싼다.
SECTION 04

비교와 논리 — True / False

조건도 먼저 "평가"됩니다

if score >= 60:
    print("합격")
# score >= 60 평가 → True/False → 실행할 블록 결정

if value:도 value의 truthy/falsy를 판단합니다. 초보 단계에서는 bool(value)로 판단한다고 생각하면 좋습니다.

and / or의 핵심 — short-circuit

A and B  # A가 falsy면 B를 평가하지 않음
A or B   # A가 truthy면 B를 평가하지 않음

print("hello" and 123)  # 123
print("" or "Guest")    # Guest

Python의 and/or는 항상 bool만 반환하지 않습니다. 결과가 이미 결정되면 뒤 표현식을 평가하지 않는다는 점이 실무에서 특히 중요합니다.

프로그램이 "조건에 따라 다른 길로 간다"는 것의 핵심은 참(True)과 거짓(False)입니다. 다음 섹션 if의 토대이니 여기서 단단히 잡고 갑니다.

SECTION 06

for 와 range — 값을 하나씩 꺼내 반복하기

for는 다음 값을 하나씩 받아 이름을 다시 연결합니다

for i in range(3):
    print(i)

# 다음 값 0 → i ─▶ 0 → 본문
# 다음 값 1 → i ─▶ 1 → 본문
# 다음 값 2 → i ─▶ 2 → 본문
# 더 없으면 종료
range는 list가 아닙니다

range(5)는 숫자 목록을 미리 만든 list가 아니라 숫자 범위를 표현하는 range 객체입니다. Iterator에서 다시 연결합니다.

누적(accumulation) — reduce로 이어지는 패턴

total = 0
for n in [1,2,3,4]:
    total += n
# 0+1→1, 1+2→3, 3+3→6, 6+4→10

이전 결과를 기억하는 total 같은 값을 accumulator라고 볼 수 있습니다. Self Study의 reduce가 이 패턴을 일반화합니다.

+= 주의

숫자에서는 x += 1을 x = x + 1과 같은 결과를 만드는 짧은 표현으로 읽어도 좋습니다. 하지만 mutable 객체에서는 내부 동작까지 항상 같은 것은 아닙니다. Week 3에서 list로 확인합니다.

같은 일을 여러 번 해야 할 때 — 1부터 100까지 더하기, 문자열의 글자를 하나씩 보기 — 복사 붙여넣기로는 못 합니다. for는 반복할 수 있는 대상에서 값을 하나씩 꺼내 같은 코드를 실행합니다. 그중 range()는 정해진 횟수나 숫자 범위를 반복할 때 자주 사용합니다.

SECTION 07

while — 조건이 참인 동안 반복

if와 while은 같은 조건 평가 원리를 씁니다

if는 조건을 한 번 평가해 흐름을 고르고, while은 본문을 실행한 뒤 조건을 다시 평가합니다. while True가 계속 반복되는 이유도 매번 조건 결과가 True이기 때문입니다.

for는 반복할 대상의 값을 하나씩 꺼낼 때 잘 어울리고, while은 조건이 참인 동안 반복할 때 잘 어울립니다. 횟수가 정해진 반복은 for + range()가 특히 편하고, "사용자가 그만이라고 할 때까지", "정답을 맞힐 때까지"처럼 끝나는 시점을 조건으로 판단할 때는 while이 자연스럽습니다.

동작 순서:

  1. 조건 검사: count < 5가 True인가?
  2. True면 블록 실행

위험: 무한 루프

조건을 절대 False로 못 만들면 무한히 반복합니다. 초보자가 자주 만드는 실수 — count = count + 1을 깜빡하는 경우입니다.

무한 루프 주의

이 강의 환경에서는 무한 루프를 만들면 실행이 영원히 끝나지 않습니다. 페이지를 새로고침하거나 다른 코드 블록을 실행해서 빠져나오세요. while을 쓸 때는 "이 반복은 어떻게 끝나는가?"를 늘 생각하는 습관이 중요합니다.

실행 흐름은 간단합니다. 변환에 실패하면 except에서 안내하고 다시 반복합니다. 변환에 성공하면 break가 실행되어 반복을 끝냅니다.

for vs while — 언제 무엇을?

  • range, 문자열, 나중에 배울 리스트처럼 반복할 대상이 있다 → for
  • 조건이 참인 동안 계속하고, 언제 끝날지 조건으로 판단한다 → while

예시:

  • "학생 30명 점수 합산" → 학생들을 하나씩 처리 → for
  • "문자열의 각 글자 확인" → 글자를 하나씩 처리 → for
  • "정답 맞힐 때까지 묻기" → 끝나는 조건을 검사 → while
  • "사용자가 q를 입력할 때까지 계속" → 끝나는 조건을 검사 → while
이 섹션의 핵심
  • while 조건: — 조건이 True인 동안 반복.
  • 조건을 False로 만들 코드가 안에 반드시 있어야 — 안 그러면 무한 루프.
  • while True: + break — 의도적 무한 + 빠져나오기 패턴.
  • try/except와 합치면 잘못된 입력을 다시 받는 실전 패턴을 만들 수 있다.
  • 반복할 대상의 값을 하나씩 처리 → for, 조건이 참인 동안 계속 → while.
